# Прогнозирование стоимости недвижимости

Учебный проект: модели регрессии для предсказания цены объекта недвижимости
по датасету **Zingat** (объявления о недвижимости в Турции, 2018–2019).

## Структура проекта

```
real_estate_price/
├── data/
│   ├── real_estate_data.csv     # исходный датасет (403 487 объявлений)
│   └── zingat_data_info.docx    # описание столбцов от авторов датасета
├── real_estate_price.ipynb      # основной notebook: EDA, предобработка, модели
├── app.py                       # приложение Streamlit: прогноз, дашборд, справка
├── model.pkl                    # обученная модель + препроцессоры (создаётся notebook-ом, в репозиторий не входит)
├── app_data.csv                 # очищенные данные для дашборда
├── app_metrics.csv              # метрики моделей для дашборда (создаётся notebook-ом)
├── requirements.txt             # версии зависимостей
├── .gitignore                   # исключает большие файлы из репозитория
└── README.md
```

## Запуск

```bash
pip install -r requirements.txt
```

Откройте `real_estate_price.ipynb` и выполните «Run All». Полный прогон занимает
порядка 20–30 минут — основное время уходит на подбор гиперпараметров и обучение
ансамблей. Notebook создаёт `model.pkl`, `app_data.csv` и `app_metrics.csv`.

После этого запускается приложение:

```bash
streamlit run app.py
```

Приложение откроется в браузере на `http://localhost:8501`.

**Важно:** `model.pkl` весит больше лимита GitHub на размер файла, поэтому
в репозиторий он не входит — его создаёт notebook. Без него приложение
не запустится и скажет об этом явным сообщением.

## Что сделано

| Этап | Содержание |
|---|---|
| Этап 1 | EDA: структура данных, описательные статистики, 6 типов графиков, анализ пропусков, дубликатов и аномалий, гипотезы |
| Этап 2 | Очистка данных, обработка выбросов, feature engineering, проверка мультиколлинеарности, разбиение 70/15/15, кодирование и масштабирование без утечки данных |
| Этап 3 | 6 моделей разной природы, подбор гиперпараметров по кросс-валидации, 4 метрики, сравнительная таблица и графики |
| Этап 4 | Сохранение модели и препроцессоров в `model.pkl`, приложение на Streamlit |

## Приложение

| Вкладка | Что внутри |
|---|---|
| Прогноз цены | Форма со всеми характеристиками объекта, валидация ввода, прогноз с диапазоном ±MAE и ценой за м² |
| Дашборд | KPI, 6 интерактивных графиков с фильтрами по городу, цене и типу жилья, таблица сравнения моделей |
| Справка | Описание приложения и полей, метрики модели, ограничения, версия и авторство |

Модель загружается один раз при старте через `@st.cache_resource`, а не на каждый
запрос. Данные для дашборда кешируются через `@st.cache_data`.

## Модели

| Модель | Тип |
|---|---|
| Ridge | линейная |
| DecisionTreeRegressor | одиночное дерево |
| RandomForestRegressor | ансамбль — бэггинг |
| GradientBoostingRegressor | ансамбль — бустинг |
| HistGradientBoostingRegressor | ансамбль — быстрый бустинг |
| StackingRegressor | ансамбль — стекинг |

Метрики: **MAE**, **RMSE**, **MAPE**, **R²**. Модель обучается на логарифме цены,
метрики считаются в лирах.

### Результат

| | MAE | MAPE | R² |
|---|---|---|---|
| Случайный лес (лучший по метрикам) | 97 233 | 19.20% | 0.73 |
| Стекинг | 99 951 | 19.81% | 0.74 |
| Ridge (худший) | 144 411 | 30.43% | 0.54 |

**Финальная модель** — случайный лес из 15 деревьев: на тесте MAE 100 406,
MAPE 20.06%, R² 0.71. Выбран не только по метрикам, но и с учётом практических
соображений: лес из 200 деревьев весит 1.5 ГБ, из 15 — 118 МБ, при разнице
в точности около одного процентного пункта. Компактная модель быстрее грузится
и не упирается в ограничения по памяти.

## Воспроизводимость

`RANDOM_STATE = 42` зафиксирован для разбиения выборки и всех моделей.
Версии библиотек — в `requirements.txt`.

## Защита от утечки данных

* Признак «цена за м²» намеренно **не используется** — он вычисляется из целевой переменной.
* `tom` (время на рынке) и `end_date` не используются — они становятся известны
  уже после публикации объявления.
* Медианы для заполнения пропусков, One-Hot кодировщик и `StandardScaler`
  обучаются **только на train**.
* Тестовая выборка используется один раз, в самом конце.
