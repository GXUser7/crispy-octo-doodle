# Рекомендательная система фильмов

Проект представляет собой веб-приложение для подбора рекомендаций фильмов с использованием нескольких подходов машинного обучения. Система разделена на три основные части:

1. **`train_models.ipynb`** — исследовательский блокнот: загрузка и очистка данных, анализ датасета, построение и проверка алгоритмов рекомендаций, сохранение обученных моделей в папку `models/`.
2. **`api.py`** — серверная часть (REST API на `FastAPI`): загружает готовые модели из `models/`, хранит новые оценки пользователей в базе данных `SQLite` (`recsys.db`) и обрабатывает запросы на рекомендации.
3. **`app.py`** — пользовательский интерфейс (`Streamlit`): позволяет искать фильмы, ставить им оценки, проверять работу разных алгоритмов и тестировать холодный старт.

---

## Используемые данные (`data/`)

В основе проекта лежат три CSV-файла из набора данных фильмов и оценок:
- `data/movies_metadata.csv` — информация о фильмах (`45 466` строк: название, жанры, дата выхода, описание);
- `data/links_small.csv` — таблица связей между идентификаторами (`9 125` записей);
- `data/ratings_small.csv` — оценки пользователей (`100 004` оценки).

После очистки, извлечения жанров и года выпуска и объединения таблиц в `train_models.ipynb` получена итоговая выборка:
- **99 810** оценок;
- **671** пользователь (ID `1–671`);
- **9 025** фильмов.

## Описание основных файлов

### 1. `train_models.ipynb` (анализ данных и обучение моделей)
В блокноте последовательно выполняются:
- **Анализ и визуализация данных:** графики распределения оценок пользователей, топ-10 популярных жанров и топ-10 фильмов по взвешенному рейтингу.
- **Подход 1 — Популярные фильмы и фильтрация на знаниях:**
  - Расчёт взвешенного рейтинга IMDb: `w_score = ((v * R) + (m * c)) / (v + m)`, где `v` — количество оценок фильма, `R` — средняя оценка фильма, `m = 28.0` — порог доверия (90-й процентиль числа оценок), `c = 3.29` — средняя оценка по всем фильмам.
  - Фильтрация по заданному жанру и минимальному году выхода.
- **Подход 2 — Контентная фильтрация:**
  - Объединение жанров и описания фильма (`genres + overview`), векторизация текста через `TfidfVectorizer(stop_words='english', max_features=10000)` в матрицу размером `(9025, 10000)` и поиск похожих фильмов по косинусному сходству (`cosine_similarity`).
- **Подход 3 — Коллаборативная фильтрация:**
  - Построение матрицы оценок размером `(671 × 9025)` (пользователи × фильмы).
  - Сравнение фильмов через корреляцию (`corrwith` для фильмов с количеством оценок `>= 30`).
  - Обучение двух моделей `NearestNeighbors(metric='cosine', algorithm='brute')`: по фильмам (`Item-based`) и по пользователям (`User-based`).
- **Подход 4 — Гибридный подход и холодный старт:**
  - Объединение коллаборативной (`50%`) и контентной (`50%`) составляющих: `0.5 * collab + 0.5 * content`.
  - Обработка холодного старта: если у пользователя ещё нет оценок, система возвращает топ популярных фильмов по `w_score`.
- **Сохранение артефактов в папку `models/`:**
  - `models/movies.pkl` — очищенная таблица фильмов и статистик;
  - `models/users_pivot.pkl` — матрица оценок пользователей;
  - `models/tfidf_matrix.pkl` — TF-IDF матрица описаний и жанров;
  - `models/model_knn.pkl` — обученная модель KNN для поиска похожих фильмов;
  - `models/model_user_knn.pkl` — обученная модель KNN для поиска похожих пользователей.

### 2. `api.py` (бэкенд на FastAPI)
Сервер запускается на `http://127.0.0.1:8000` (интерактивная документация Swagger доступна по адресу `http://127.0.0.1:8000/docs`), при первом запуске создаёт базу `recsys.db` с таблицей `user_ratings` и предоставляет 13 маршрутов:

| Метод и маршрут | Назначение |
| :--- | :--- |
| `GET /help` | Список всех команд API |
| `GET /movies?search=...&limit=30` | Поиск фильма по названию |
| `GET /movies/{movie_id}` | Подробная карточка фильма (описание, средний рейтинг, число оценок) |
| `GET /genres` | Список всех уникальных жанров |
| `GET /popular?n=10&genre=...&min_year=0` | Топ популярных фильмов (с фильтром по жанру и году) |
| `GET /recommend/content/{movie_id}?n=10` | Похожие фильмы по описанию и жанрам (TF-IDF) |
| `GET /recommend/similar/{movie_id}?n=10` | Похожие фильмы по оценкам зрителей (KNN) |
| `GET /recommend/user/{user_id}?n=10` | Рекомендации по 20 похожим пользователям (с холодным стартом) |
| `GET /recommend/hybrid/{user_id}?n=10` | Персональные гибридные рекомендации (`50%` KNN + `50%` TF-IDF) |
| `GET /recommend/by-rating/{movie_id}?rating=5&user_id=0` | 5 рекомендаций сразу после оценки фильма |
| `POST /rate` | Сохранение оценки (`0.5–5.0`) в базу SQLite `recsys.db` |
| `GET /users/new` | Выдача нового свободного ID пользователя (от `672`) |
| `GET /users/{user_id}/ratings` | Список всех оценок выбранного пользователя |

### 3. `app.py` (веб-интерфейс на Streamlit)
Подключается к запущенному `api.py`, позволяет в боковой панели выбрать ID пользователя (`1–671` — из датасета, от `672` — новые пользователи сайта) и переключиться между 8 режимами:
1. **Оценить фильм** — поиск фильма, просмотр описания, выставление оценки (`0.5–5.0`) с сохранением в базу и моментальным показом 5 рекомендаций (при оценке `>= 4` — похожих фильмов, при `< 4` — популярных фильмов других жанров).
2. **Топ популярных и фильтр на знаниях** — выбор жанра и минимального года выхода.
3. **По описанию (контентная фильтрация)** — подбор фильмов со схожим сюжетом и жанрами.
4. **Похожие фильмы (коллаборативная KNN)** — подбор фильмов со схожими оценками зрителей.
5. **По похожим людям (коллаборативная KNN)** — рекомендации от 20 пользователей с похожим вкусом (при отсутствии оценок срабатывает холодный старт).
6. **Персональные (гибридный подход)** — комбинация коллаборативного и контентного подходов.
7. **Мои оценки** — просмотр всех оценённых пользователем фильмов.
8. **Справка** — описание режимов и перечень маршрутов API.

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install fastapi uvicorn pydantic pandas numpy scipy scikit-learn streamlit requests matplotlib seaborn jupyter
```

### 2. Подготовка моделей (если папка `models/` ещё не создана)
Откройте и выполните все ячейки блокнота `train_models.ipynb` — он обработает файлы из `data/` и сохранит готовые модели в `models/`.

### 3. Запуск сервера и веб-приложения
Откройте два окна терминала в папке проекта:

**Терминал 1 — запуск API:**
```bash
python api.py
```

**Терминал 2 — запуск интерфейса:**
```bash
streamlit run app.py
```

После запуска интерфейс откроется в браузере автоматически, а API будет доступен по адресу `http://127.0.0.1:8000` (документация — `http://127.0.0.1:8000/docs`).
