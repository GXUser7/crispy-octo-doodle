# Прогнозирование стоимости недвижимости

Проект: модели регрессии для предсказания цены продажи и месячной аренды
объекта недвижимости по датасету **Zingat** (объявления о недвижимости в Турции, 2018–2019).

## Структура проекта

```
real_estate_price/
├── data/
│   ├── real_estate_data.csv     # исходный датасет (403 487 объявлений)
│   ├── test_real_estate_samples.csv  # 20 объектов для проверки модели (Этап 5)
│   └── zingat_data_info.docx    # описание столбцов от авторов датасета
├── real_estate_price.ipynb      # основной notebook: EDA, предобработка, модели, проверка
├── result_real_estate_samples.csv  # прогноз для 20 объектов + ФИО и группа (Этап 5)
├── app.py                       # приложение Streamlit: прогноз, дашборд, справка
├── model.pkl                    # обученная модель + препроцессоры (создаётся notebook-ом, в репозиторий не входит)
├── app_data.csv                 # очищенные данные для дашборда
├── app_metrics.csv              # метрики моделей для дашборда (создаётся notebook-ом)
├── requirements.txt             # версии зависимостей
├── .gitignore                   # исключает большие файлы из репозитория
└── README.md
```

## Запуск

```bash
pip install -r requirements.txt
```

Откройте `real_estate_price.ipynb` и выполните «Run All». Полный прогон занимает
порядка 20–30 минут — основное время уходит на подбор гиперпараметров и обучение
ансамблей. Notebook создаёт `model.pkl`, `app_data.csv`, `app_metrics.csv`
и `result_real_estate_samples.csv`.

После этого запускается приложение:

```bash
streamlit run app.py
```

Приложение откроется в браузере на `http://localhost:8501`.

**Важно:** `model.pkl` весит больше лимита GitHub на размер файла, поэтому
в репозиторий он не входит — его создаёт notebook. Без него приложение
не запустится и скажет об этом явным сообщением.

## Что сделано

| Этап | Содержание |
|---|---|
| Этап 1 | EDA: структура данных, описательные статистики, 6 типов графиков, анализ пропусков, дубликатов и аномалий, гипотезы. Продажа и аренда остаются в данных, тип объявления становится признаком |
| Этап 2 | Очистка данных, обработка выбросов (свои границы цены для продажи и аренды), feature engineering, проверка мультиколлинеарности, разбиение 70/15/15 со стратификацией по типу объявления, кодирование и масштабирование без утечки данных |
| Этап 3 | 6 моделей разной природы, подбор гиперпараметров по кросс-валидации, 4 метрики, сравнительная таблица и графики |
| Этап 4 | Сохранение модели и препроцессоров в `model.pkl`, приложение на Streamlit |
| Этап 5 | Проверка модели на 20 объектах из `test_real_estate_samples.csv`: прогноз, MAE/RMSE/R² вручную и через sklearn, анализ результатов, `result_real_estate_samples.csv` |

## Приложение

| Вкладка | Что внутри |
|---|---|
| Прогноз цены | Выбор «продажа / аренда», форма со всеми характеристиками объекта, валидация ввода, прогноз с диапазоном ±MAE и ценой за м² |
| Дашборд | KPI, 6 интерактивных графиков с фильтрами по типу объявления, городу, цене и типу жилья, таблица сравнения моделей |
| Справка | Описание приложения и полей, метрики модели, ограничения, версия и авторство |

Модель загружается один раз при старте через `@st.cache_resource`, а не на каждый
запрос. Данные для дашборда кешируются через `@st.cache_data`.

## Модели

| Модель | Тип |
|---|---|
| Ridge | линейная |
| DecisionTreeRegressor | одиночное дерево |
| RandomForestRegressor | ансамбль — бэггинг |
| GradientBoostingRegressor | ансамбль — бустинг |
| HistGradientBoostingRegressor | ансамбль — быстрый бустинг |
| StackingRegressor | ансамбль — стекинг |

Метрики: **MAE**, **RMSE**, **MAPE**, **R²**. Модель обучается на логарифме цены,
метрики считаются в лирах. Тип объявления (`listing_type`: продажа или аренда)
передаётся модели как признак.

### Результат

| | MAE | MAPE | R² |
|---|---|---|---|
| Случайный лес (лучший по метрикам) | 67 359 | 20.57% | 0.75 |
| Стекинг | 69 797 | 21.08% | 0.75 |
| Ridge (худший) | 101 939 | 30.65% | 0.54 |

Метрики на валидации по продаже и аренде вместе; MAE в лирах определяется в основном продажей.

**Финальная модель** — случайный лес из 15 деревьев. На тестовой выборке:

| | MAE | MAPE | R² |
|---|---|---|---|
| Продажа | 99 040 лир | 19.75% | 0.71 |
| Аренда | 722 лир в месяц | 24.89% | 0.57 |

Модель выбрана не только по метрикам, но и с учётом практических
соображений: лес из 200 деревьев весит 2.2 ГБ, из 15 — 168 МБ, при разнице
в точности меньше одного процентного пункта. Компактная модель быстрее грузится
и не упирается в ограничения по памяти.

## Воспроизводимость

`RANDOM_STATE = 42` зафиксирован для разбиения выборки и всех моделей.
Версии библиотек — в `requirements.txt`.

## Защита от утечки данных

* Признак «цена за м²» намеренно **не используется** — он вычисляется из целевой переменной.
* `tom` (время на рынке) и `end_date` не используются — они становятся известны
  уже после публикации объявления.
* Медианы для заполнения пропусков, One-Hot кодировщик и `StandardScaler`
  обучаются **только на train**.
* Тестовая выборка используется один раз, в самом конце.
